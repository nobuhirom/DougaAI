# 方式決定 — レンダリング基盤と TTS

決定日: 2026-09-15
前提: [01_調査メモ.md](01_調査メモ.md) / [02_論点整理.md](02_論点整理.md)

`02_論点整理.md` の Q1（レンダリング基盤）と Q4-1（TTS）を決定する。他の論点はこの決定に従属する。

---

## 決定1: レンダリング基盤は **Remotion**

### 判断の軸: 「壊れ方」

本システムは **AI がコードとデータを書く**ことを前提にしている。この前提下では、**壊れているのに完走してしまう**性質が最大のリスクになる。AI は自分が出した動画を目視できないため、サイレント失敗は検知されないまま成果物に混入する。

`01_調査メモ.md` にも「CSS が壊れていてもレンダリングは完走する（正常終了・エラー0・警告0 で、キャラが消えた動画ができる）」という指摘があった。公式ドキュメント調査で、この種の落とし穴が HyperFrames に複数あることを確認した。

| # | サイレント失敗 | 出典 |
| --- | --- | --- |
| 1 | サブコンポジションの `<template>` 外に置いた `<style>` / `<script>` は**無言で破棄**される | [sub-compositions.md](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes-core/references/sub-compositions.md) |
| 2 | `data-composition-id` の不一致は lint で検出できず、レンダー時に45秒タイムアウト | 同上 |
| 3 | `data-start="intro-0.5"`（演算子前後のスペース欠落）は ID 参照と誤解釈され**サイレントに0秒扱い** | [data-attributes.md](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes-core/references/data-attributes.md) |
| 4 | `<audio>` に `id` が無いとミキサーが認識せず**無音でレンダリング**される | [variables-and-media.md](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes-core/references/variables-and-media.md) |
| 5 | `crossorigin` 属性を付けると**プレビューだけが壊れ、レンダーは通る** | 同上 |
| 6 | フォントファイルを同梱せずシステム日本語フォント名を指定すると**無言で汎用フォントにフォールバック** | [frame-worker-core.md](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes/references/frame-worker-core.md) |

Remotion は TypeScript の型と zod スキーマでレンダー前に停止する。`lint` が「検出できないことがある」のではなく、コンパイルが通らない。**この差が決定的**と判断した。

### その他の比較

| 観点 | Remotion | HyperFrames |
| --- | --- | --- |
| ライセンス | source-available。**個人は商用含め無償**（4人以上の組織で有償） | Apache-2.0（完全 OSS） |
| 成熟度 | v4.0.524、安定運用フェーズ | **v0.8.40（プレ1.0）**。2026-09-07〜14 の8日間で10リリース |
| 既知の CJK 問題 | 日本語改行は公式に言及なし → 自前実装 | [#3353](https://github.com/heygen-com/hyperframes/issues/3353) CJK 字幕が1キューに潰れる（Closed）、[#3583](https://github.com/heygen-com/hyperframes/issues/3583) フォント未ステージング（**Open**） |
| 可変長セリフの連結 | `calculateMetadata` で音声長から総尺確定 → `<Series>` が開始フレームを自動積算（公式の定石） | 音声長→尺の**統合手段なし**。スクリプト側で `data-start` / `data-duration` を計算して埋める |
| 離散アニメーション（口パク） | `frame % n` | `Math.floor(t/0.1) % n` + `setAttribute` |
| スキーマ検証 | `@remotion/zod-types` で公式サポート | — |
| 実績 | 事例A（`01_調査メモ.md`）が**同一形式で実運用中** | — |

### HyperFrames の強みが本件で効かない理由

`01_調査メモ.md` が挙げる HyperFrames 適性条件と、本件の前提を突き合わせる。

| HyperFrames が向く条件 | 本件では |
| --- | --- |
| React を知らず今後も Web 開発をやらない | **AI がコードを書く**。React を人間が書く必要がない |
| 「いい感じに大きく」とふんわり指示したい | 型から選ばせる方針（P4）と逆行する |
| 画面を触ってドラッグで調整したい | 量産では1本ごとの手調整をなくしたい |
| プロンプトから一気に1本、HTML 1枚で完結 | 量産型・部品を育てる方針 |
| **生成AIで作った動画クリップを切り貼りして繋げる** | 動画生成 AI を使わない（P1） |

### コスト

Remotion は source-available で OSI 的な OSS ではないが、**個人利用は商用利用を含めて無償**。無償枠は「個人、または関係者3人までの組織」。本件は個人プロジェクトのため課金は発生しない。

- YouTube 収益化を名指しで禁じる条項はなく、「Remotion 自体を販売する、またはライセンス購入を回避させる目的でない限り、あらゆる商用利用が許可される」の一般条項の範囲内
- 4人以上（外部委託者を含む）になった時点で有償: Creators $25/シート/月、または完全自動パイプライン向け Automators $0.01/レンダリング・最低 $100/月
- 出典: [LICENSE.md](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md) / [license/terms](https://www.remotion.dev/docs/license/terms) / [license/faq](https://www.remotion.dev/docs/license/faq)

**この条件は将来 OSS 化・サービス化する場合に効いてくる**（Q7-3）。他人を巻き込む規模になったら再検討する。

## 決定2: HyperFrames CLI は「道具」として確保する（初版では使わない）

不採用は「レンダリング基盤として」であって、CLI ユーティリティは別に評価できる。

`tts` / `transcribe` / `remove-background` / `beats` はコンポジション HTML やタイムラインと無関係な独立サブコマンドで、任意のローカル音声・動画ファイルを入出力とする。インストール単位は単一 npm パッケージ `@hyperframes/cli` で、`npx hyperframes <subcommand>` で個別に呼べる。

| コマンド | 中身 | 本件での使い道 |
| --- | --- | --- |
| `transcribe` | whisper.cpp ローカル実行、**単語タイムスタンプ付き JSON** を出力 | **Irodori TTS が返さないアライメント情報を埋められる**。カラオケ字幕・精密な口パクをやるなら必要 |
| `remove-background` | u2net（MIT、オンデバイス ONNX）、CoreML 対応 | 実写素材を使う場合の人物切り抜き |
| `beats` | 音声のビート検出 | BGM に合わせたカット割り |
| `tts` | Kokoro-82M ローカル固定（日本語 `jf_*` 音声あり、`espeak-ng` 要） | Irodori TTS を採用するため不要 |

**初版では使わない**。依存を増やさず、必要が生じた時点で `devDependency` として足す。`transcribe` を使う場合は `--model small --language ja` のように `.en` なしモデル＋言語コード指定が必須（`.en` 系モデルは日本語音声を強制的に英語へ翻訳してしまう）。

## 決定3: TTS は **Irodori TTS**

[Aratako/Irodori-TTS](https://github.com/Aratako/Irodori-TTS)（最新 v4.1-Small、0.8B、2026-08-11）。

| 項目 | 内容 |
| --- | --- |
| ライセンス | **コード・モデル重みとも MIT**。公開・収益化の制約なし |
| 実行形態 | ローカル実行（Python + uv）。`uv sync --extra cpu` で **CPU/MPS 対応** |
| API | 別リポジトリ [Irodori-TTS-Server](https://github.com/Aratako/Irodori-TTS-Server) が **OpenAI TTS 互換**。`speed` 0.25〜4.0、wav/mp3 等6形式、長文自動チャンキング |
| 声の固定 | 参照音声によるゼロショットクローン、`--ref-embed` で埋め込み再利用、`--caption` で声質を自然文指定 |
| 感情制御 | **絵文字埋め込み**でスタイル・感情・非言語音を制御 |
| 出力 | WAV 48kHz |

VOICEVOX のキャラクター別規約や、クラウド API の従量課金と比べ、**MIT かつローカル完結**という点が「何本作っても定額」というコスト設計（P1 の延長）に最も合う。

### 設計に効く制約

1. **単語/音素単位のタイムスタンプを返さない**（調査範囲で該当機能を発見できず）
   - 音声全体の長さは `ffprobe` で取得できるため、「音声長から duration を決める」方式（Q4-4）は成立する
   - カラオケ字幕・精密な口パクが必要になったら HyperFrames `transcribe` を足す
2. **読み指定（漢字の読み・アクセント）の明示的手段が見当たらない**
   - 固有名詞・技術用語は**台本側でカタカナ書きして吸収**する運用にする
   - 読み辞書が必須になったら VOICEVOX / Style-Bert-VITS2 との併用を再検討
3. **SilentCipher による電子透かしが自動付与される**
   - 収益化を妨げるものではないが、YouTube の合成コンテンツ開示ポリシーとは別途向き合う
4. **モデルカードに倫理ガイドラインがある**
   - 「実在人物の声を本人同意なくクローンするな」「誤解を招くディープフェイクに使うな」
   - **参照音声は自分で用意した、または権利のクリアな音源に限定する**

## 調査メモの訂正

`01_調査メモ.md` に事実誤認が1件あった。公式ドキュメントで確認した結果を記録する。

| 誤 | 正 |
| --- | --- |
| 「HyperFrames の Audio / Video は**ルート直下にしか置けない**。子コンポーネント内に置くと再生されない」 | 公式は「`<video>`/`<audio>` は**サブコンポジションの `<template>` 内を含め、任意のネスト深度で動作する**」と明記。実際の制約は「`data-start` を持つ祖先要素の内側に `<video data-start>` を置いてはいけない（lint が `video_nested_in_timed_element` で拒否）」という別物 |

出典: [variables-and-media.md](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes-core/references/variables-and-media.md)

この訂正は決定を変えない（決め手はサイレント失敗の多さであって、この制約ではない）。

なお `01_調査メモ.md` の HyperFrames 実績値（Stars 38,193）は動画公開時点（2026-07-30）のもので、2026-09-15 時点では **Stars 50,256 / Forks 4,583 / Open Issues 143**。勢いは継続している。

## Remotion 採用にあたっての注意点

実装時に踏まないよう記録する。

| # | 内容 | 出典 |
| --- | --- | --- |
| 1 | `<Audio>` は `<Html5Audio>` に改称済み。**新規は `@remotion/media` の `<Audio>` を使う** | [docs/audio](https://www.remotion.dev/docs/audio) |
| 2 | `getAudioDurationInSeconds()` は deprecated。`getMediaMetadata()` が推奨 | [docs/get-audio-duration-in-seconds](https://www.remotion.dev/docs/get-audio-duration-in-seconds) |
| 3 | v5.0（未リリース）で `@remotion/media-parser` / `@remotion/webcodecs` ほか4パッケージが**廃止予定**。→ **直接依存しない設計にする** | [docs/5-0-migration](https://www.remotion.dev/docs/5-0-migration) |
| 4 | 日本語の改行・禁則処理は公式に対応を明記していない。**自前実装が前提** | 調査範囲で記載を発見できず |
| 5 | Apple Silicon での実レンダリング時間は公式に数値なし。`npx remotion benchmark` で実測し `--concurrency` を決める | [docs/performance](https://www.remotion.dev/docs/performance) |
| 6 | フォントはシステムフォント名に依存せず**ファイルを同梱して `@font-face` で読む**（HyperFrames の教訓を先回りして適用） | — |
| 7 | **Studio のビジュアル編集はソースファイルを書き換える。** プレビュー上で要素をドラッグすると `@remotion/studio-codemods` が JSX を直接編集する（`apply-visual-control` / `insert-jsx-element` / `delete-jsx-node` / `reorder-sequence` 等）。**これを止める設定は Remotion 側にない**（`Config` に該当する項目を発見できず）。Studio は見るだけにして、レイアウトは `src/remotion/theme.ts` を直して変える | 2026-09-15 に実際に踏んだ（下記） |

### Studio の書き戻しで実際に起きたこと

Studio を開いたまま作業していたところ、`src/remotion/Video.tsx` に次の2件が
勝手に書き込まれていた。

```diff
-      style={{
-        background: `linear-gradient(...)`,
-      }}
-    />
+style={{
+background: `linear-gradient(...)`,
+translate: "2px 0px"
+}}
+/>

-    <AbsoluteFill style={{ backgroundColor: COLORS.backgroundTop }}>
+    <AbsoluteFill style={{ backgroundColor: COLORS.backgroundTop }} from={-299}>
```

インデントも崩れる。`from` は `AbsoluteFill` の props にないため型エラーになり、
そこで気づけたが、`translate` のような有効な CSS プロパティだけなら
**型検査を通り抜けて動画に混入する**。

決定性（N1）を前提にしている以上、意図しない書き換えが混ざる経路は塞ぐ。

**運用**: Studio はプレビュー専用にする。要素をドラッグしない。
レイアウトを変えるときは `src/remotion/theme.ts` を編集する（寸法はそこに集約してある）。
作業を終えたら Studio を閉じる。
