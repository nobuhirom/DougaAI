# 楓 — キャラクターシート（画像生成用）

立ち絵を GPT Images（Codex の組み込み `image_gen`）で作るときの、毎回同じ記述を入れる
「変えない要素」。表情や口の差分を作るたびにこの文言をプロンプトへ貼る
（docs/07_品質方針.md 3.2）。

## 絵柄

日本のアニメ調のフラットなイラスト。均一で影の少ない塗り、太すぎない輪郭線。
背景は純白（#FFFFFF）、装飾・小物・影・文字なし（後で `tools/characters/make-sprite.sh` で透過にする）。

## 変えない要素（差分生成のたびに明記する）

- 髪: 長い紺色（ネイビー）。前髪は額が少し見える程度
- 顔: 輪郭、目の形、瞳の色（ダークブラウン）、眉
- 服: ダークブルーの襟付きのシンプルな上着
- ポーズ: 正面、腰から上のバストアップ、両腕は体の横
- 画角: 縦長 3:4。人物の位置とサイズを元画像と同じに
- 線の太さと塗りのフラットさ

## 差分の作り方

ベース（`base.png`、無表情・口閉じ）を `referenced_image_paths` で渡し、
**変える箇所だけ**を指示する。

| 差分 | 指示 |
| --- | --- |
| happy | 目を少し細めて微笑み、口は閉じたまま口角を上げ、頬をわずかに赤らめる |
| surprised | 目を見開き、眉を上げ、口を小さく「お」の形に |
| thinking | 視線をやや上へ、片眉を少し上げ、口は閉じる |
| trouble | 眉尻を下げ、口を「へ」の字に |
| explain | ベースとほぼ同じ。口角をわずかに上げる程度 |
| 口 half / open | 表情は元のまま、口だけを半開き／発音中の開きに |

揃わない差分は捨てて作り直す。6種が揃わなければ 3種（normal / happy / surprised）に減らす。
