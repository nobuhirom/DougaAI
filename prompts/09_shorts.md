# ショートを切り出す

**入力**: `projects/<id>/script.json`（と `build/<id>/manifest.json` の尺）
**出力**: `projects/<id>/shorts.json`

本編から、単体で成立する 60 秒以内の断片を切り出す。音声は本編のものをそのまま使うので
セリフを書き換えない。書き換えたくなったら本編の台本を直す。

## 出力の形

```json
{
  "shorts": [
    {
      "id": "why-json",
      "title": "台本はJSON一枚",
      "hook": "編集ソフトを使わない理由",
      "lineIds": ["s0_intro_002", "s0_intro_003", "s0_intro_004"]
    }
  ]
}
```

## 守ること

- **1本 60 秒以内**（`douga check` が本編の尺から計算して落とす）
- **`hook` は 24 文字以内**。冒頭 2 秒で内容が伝わる一言。疑問形か、結論の言い切り
- 行は本編の順序どおりに並べる。順序を入れ替えない（文脈が壊れる）
- 切り出した行だけで意味が通ること。「さっき言ったように」など前を参照する行を先頭にしない
- ビジュアルは本編の行に付いているものがそのまま出る。切り出し先頭の行にビジュアルが無いと
  直前のビジュアルが引き継がれないので、**先頭は `visual` を持つ行から始める**のが無難
- 1本の動画から 1〜3 本。多く作るより、単体で面白い断片を選ぶ

## 書いたあと

```bash
npm run douga -- check <id>     # 行 id の実在と尺
npm run douga -- shorts <id>    # 縦 9:16 で out/<id>-<shortId>.mp4 を焼く
```
